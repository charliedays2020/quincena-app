# Quincena a Quincena (Android)

App personal de control de gastos por quincena: sueldo en US$, compromisos en lempiras, tarjetas de crédito, proyección y avisos de pago.

- `www/index.html`: la app (misma que el dashboard).
- `.github/workflows/android.yml`: GitHub compila el `.apk` en cada cambio. Se descarga en **Actions › última ejecución › Artifacts**.
- Los datos se guardan solo en el teléfono. Este repositorio no contiene datos personales.
